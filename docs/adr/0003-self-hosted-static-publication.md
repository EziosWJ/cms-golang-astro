# ADR-0003：首版同机静态发布与成功边界

状态：Accepted

首版采用同机自托管，由独立 Builder 构建 Astro，Web 服务器提供静态站点；暂不接入远端部署平台，以减少凭据、传输及远端切换依赖。CMS 日常运行不依赖 Node，构建环境需要 Node，CMS 与站点构建仍彼此独立。

发布任务按站点串行，固定待发布内容版本；只有构建完成且线上版本切换成功才算发布成功，失败保留原站点。该约定排除了仅更新数据库状态或仅构建成功就标记发布成功的做法。重试固定目标内容但采用最新线上基线，防止撤回其他成功发布；切换与数据库记账之间的中断通过持久化意图及部署指针核实恢复，详见 [Phase 1 设计](../specs/phase-1-content-design.md)。
