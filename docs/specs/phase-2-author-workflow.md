# Phase 2 Spec：作者写作、预览与发布工作流

状态：已确认产品决策，已发布 [Spec #21](https://github.com/EziosWJ/cms-golang-astro/issues/21)；功能编码与本地验证已接入，仍待真人独立试用及逐项验收；见 [验证记录](phase-2-validation.md)。

父阶段：[Phase 2 总纲](phase-2-productization.md)。任务入口：[Tickets](../tickets/phase-2/README.md)。领域术语沿用 [CONTEXT](../../CONTEXT.md)，页面文案使用作者可理解的名称，不要求用户学习内部版本号、manifest 或 release key。

## 1. 身份、导航与文章发现

登录页及外壳统一使用“CMS 内容管理”；登录后显示站点名称，尚未配置时显示明确设置入口。文章列表为默认登录落点，保留合法的原页面登录返回路径。编辑/发布/设置权限沿用服务器校验，导航收纳不修改已有系统模块语义或权限。

主要入口为文章、分类与标签、媒体、站点设置、发布记录；工作台为次级概览；用户/角色/部门/字典/文件/日志等收至系统区域。“配置发布授权”等权限点不作为普通业务页面入口。媒体库与系统文件管理仍承担不同职责。

文章列表默认显示全部未归档文章。草稿指当前未上线且未归档的文章（包括已下线但可编辑的文章）；已发布指当前线上可见；有未发布修改指线上可见且工作稿与线上内容不同。后两者可以重叠，不能把筛选改成互斥生命周期状态。归档有独立次级视图。

优先显示标题、状态、分类与最近编辑时间；标题可进入编辑。文章地址与内部版本信息为详情辅助信息。搜索/筛选、返回列表位置尽量保留。空态指向新建文章，错误态支持重试；真实无数据与加载失败有区别。

工作台仅展示授权范围内的真实最近编辑、未发布修改、最近发布结果，以及新建/查看网站入口。缺少内容时使用空态，不显示路由地址、权限点或假指标。

## 2. 写作布局与基础设置

桌面编辑器首屏包含标题和正文入口，固定操作区包含保存状态、保存版本、网站效果预览及发布/发布更新。文章设置包含摘要、封面、分类标签、展示日期、文章地址及历史入口；正文不被完整媒体列表挤到下方。

默认源码编辑，允许切换正文预览或分屏；正文即时预览与“网站效果预览”分别命名。复用现有编辑器与语法契约，保留中文输入法、撤销/重做、截图粘贴上传及长文编辑能力。表单控件、色彩、密度与组件使用遵循 MASTER 与现有 Patterns；写作布局作为 Form Pattern 的业务变体记录到页面覆盖文档，不能因此重写全部后台骨架。

Slug 在界面称“文章地址”，提供建议与完整公开地址展示，首次成功上线后锁定；展示日期不代表定时发布；空值在发布时确定默认日期。无站点地址时不生成假公开链接。元信息允许不完整保存，发布时按既有规则检查。

平板可正常写作；手机使用单栏编辑、预览切换和设置抽屉，可完成上传与发布。核心操作无需横向滚动或鼠标悬停，固定操作区不遮住输入及键盘焦点，长文和软键盘下仍可操作。

## 3. 自动保存、恢复与冲突

### 首次创建与持续保存

- 新文章标题或正文非空，在输入稳定约 2 秒后创建工作稿；仅打开空白编辑器不创建。中文输入法组合输入期间不抢先提交。封面/分类等临时选择随首次有效工作稿保存。
- 已有文章按文章串行保存；保存期间的新输入不会被旧响应覆盖，仍需继续保存。不完整文章可以保存，自动保存不新增历史修订、不改变线上内容。
- 首次创建响应丢失不能通过盲目重复创建产生多个文章；实现须有可核实的请求身份与恢复策略。新文章临时身份在取得 article ID 后安全迁移到正式身份，保留尚未确认保存的输入。
- 始终可见“尚未保存 / 正在保存 / 已保存 / 保存失败 / 保存冲突”。成功状态只对应服务器确认的输入快照；浏览器缓存不能显示为服务器已保存。

### 浏览器临时恢复副本

按站点、登录账号、文章（新文章使用独立临时身份）隔离；记录输入及其已知服务器基线，提供清除。副本保存内容字段和稳定媒体身份，不存凭据、文件二进制、blob URL 或生成 Markdown 文件。

刷新、断网或会话失效后的重新登录，在读取服务器内容后提示恢复/放弃，不能自动替换服务器内容。不同账号不能在页面读取、列出或恢复其他账号副本；重新登录同一账号可恢复。临时副本只在当前浏览器有效，明确提示这一限制。

浏览器存储不可用或容量不足时，显示保护能力受限但允许继续编辑；不能虚假承诺恢复成功。服务器已确认的匹配副本可清理，未确认或冲突副本不得悄悄删除。离开未保存页面仍提醒；刷新关闭前尽力缓存，不依赖卸载时的网络请求。

### 保存失败与冲突

保存失败保留输入，说明是否仅有浏览器副本，并提供重试；明确区分会话失效、网络错误、字段问题与版本冲突，不无限重试冲突或认证失败。

冲突立即停止自动保存，比较本地与最新服务器完整内容（包括元信息与引用）。可选择采用服务器内容，或经明确确认保留本地内容以最新版本继续保存；后者仍检查 expectedVersion，服务器再次变化时再次报冲突。放弃本地内容前说明影响。不能绕过服务器版本检测，不能自动合并。

## 4. 历史版本

“保存版本”保留明确修订；发布形成发布修订；自动保存仅更新工作稿。历史入口以时间、来源及标题摘要为主，内部编号次要显示。支持所选历史与当前工作稿的只读比较，覆盖正文和元信息；内容安全渲染。

恢复前说明当前未保存修改的影响；恢复仍检查版本，成功后显示“已恢复到工作稿，尚未发布”。修订不可变，恢复不直接上线，不释放已锁定 Slug 或分类标签身份；旧快照与当前冻结身份不兼容时明确要求重新选择。历史不可删除，不新增整站回滚。

## 5. 媒体与分类标签

媒体库只有一套主资源集合与分页，提供统一单/批量上传入口、文件名搜索、认证缩略图、可见进度/状态及逐项失败重试。附件使用对应信息展示；图片上传失败不插入虚假地址，上传响应丢失时重试也需防止无提示重复资源。

媒体详情可看文件名、类型、大小、图片尺寸和引用来源；当前封面/头像显示实际缩略图。插入正文遵循当前光标/选区，存储稳定路径，截图粘贴与选库插入使用一致反馈。上传成功但插入失败时保留资源，并提示从媒体库重新选择。

删除前说明影响；被工作稿、修订、配置、在途任务、预览或保留产物引用的资源受服务器保护。详情帮助找到相关引用，不以“当前没有文章引用”误判所有引用均为空。无删除权限时不提供可执行入口。私有源文件不因上传而公开。

编辑面板允许搜索、多选、清空分类标签，并按权限快捷创建后直接选中；取消或创建失败不丢文章输入。保留平面结构、首次发布名称/URL 冻结、旧名称与引用删除保护。不把既有冻结项改名当作快捷创建。

## 6. 首次设置与配置独立发布

轻量清单包含站点名称、公开地址和作者资料，允许先写文章。发布前补齐现有站点配置必填字段及有效值（含语言、时区），区分已保存配置与已上线配置。公开地址有意义的校验与字段错误不能被发布按钮掩盖。

初次文章发布若尚无线上站点配置，引导保存并明确发布配置；成功后返回原文章并让作者确认继续文章发布。配置发布失败不提交文章发布，原文章输入保留。清单不是阻断写作的强制向导。

设置页展示当前输入、已保存未发布配置与线上配置的差异；保存反馈“已保存，尚未应用到网站”，发布前提供变更摘要。配置单独发布，文章保持线上版本；未保存输入不能被误称为将要发布的配置。发布成功提供查看网站，失败给出原因与重试。

## 7. 网站效果预览与发布

网站效果预览固定所选文章内容，其他文章及配置沿用线上版本，仅认证用户可访问，不改公开指针。生成后继续编辑，显示“文章已有新修改，此预览尚未包含”，提供更新预览；不每次输入自动构建。请求完成也不能把旧预览标成当前最新。预览尚无可用配置时使用首次设置引导。

发布时先检查标题、合法唯一地址、非空正文、媒体引用及可用配置；字段错误定位到对应设置，用户可修正，不只显示笼统失败。网站预览可选。

确认说明发布这篇文章的当前内容，以及其他工作稿和未发布配置不会上线。确认后等待在途上传/保存并保存当前输入，生成固定发布版本；失败时停止提交。固定之前避免确认范围与输入变化分叉，固定后允许继续编辑，后续修改不混入任务。

任务展示排队、执行、成功、失败/中断以及执行器不可用的真实状态，不伪造百分比或把长期阻塞显示为正常执行。可离开页面并在发布记录找到任务，重开编辑器仍能辨认线上内容、在途目标与后续工作稿。上线仅以构建并成功切换后的服务器结果判定。

成功反馈“已上线”并提供查看文章；若工作稿后来改变，同时显示“仍有未发布修改”。失败/中断说明原因、当前线上状态与下一步；仅在服务器可核实原站点有效时说明原站点保持，未知指针等异常不得假报安全或成功。

“重试原版本”保留原固定目标，“发布最新修改”先保存再提交新目标；两者明确区分，同站点仍串行且有幂等保护。发布记录优先显示文章标题/配置操作、结果与时间，内部 ID、基线、产物和维护执行器控制放详情/维护区域，保留授权管理员诊断能力。

## 8. 下线与归档

下线、归档在更多操作中提供明确确认。下线成功前旧文章继续可见，成功后公开详情及聚合入口移除。下线失败保留正确反馈，不提前标记下线。

仅未上线且没有冲突在途任务的文章可归档；归档后不可编辑、保留身份与历史，退出默认列表。恢复归档只恢复工作稿编辑，不上线、不解除地址锁定。未发布文章可直接归档；不提供永久删除。

## 9. 验收矩阵

| 场景 | 必须观察到的结果 |
| --- | --- |
| 新用户首次进入 | 内容入口清晰，空态提供新建和设置清单，不出现原平台名称/内部路由 |
| 新文章空白/首次输入 | 空白不创建；有效输入约 2 秒后保存一次；响应丢失与重试不重复创建 |
| 连续输入与手动留版 | 旧响应不覆盖新输入；保存状态准确；自动保存不新增修订，保存版本新增明确历史 |
| 断网、刷新、重新登录 | 当前输入保留，同账号提示恢复；其他账号不展示；服务器内容未经确认不被替换 |
| 存储失败 | 明确临时保护不可用，可继续编辑，不承诺不存在的副本 |
| 两标签页并发 | 自动保存停止，比较与选择可操作；再次并发仍检测冲突 |
| 历史恢复 | 比较正文和设置，恢复只改工作稿；线上不变，冻结身份仍有效 |
| 上传/插图/附件 | 真实缩略图、光标插入、稳定路径；失败可重试，引用删除被保护 |
| 编辑中创建分类标签 | 无需离开文章，可选中新项；失败/取消不丢输入，冻结规则未绕过 |
| 初次配置与文章发布 | 允许先写；配置先明确发布成功，再确认文章发布；失败可返回继续 |
| 更新配置 | 差异清楚，保存与上线分开，其他文章工作稿不混入 |
| 预览后继续修改 | 真实私有预览可读；显示过期，更新后匹配新快照；匿名页面/资源不可读 |
| 发布前有新输入 | 先成功保存再固定；保存/上传失败不发布；固定后新输入不混入 |
| A 发布期间修改 A/B | A 固定目标上线，后续 A 修改保留；B 工作稿与未发布配置不泄漏 |
| 请求响应丢失 | 相同请求恢复同一任务，无重复发布；原目标仍可辨认 |
| 发布失败与中断重启 | 原有效站点保持；已切换补记成功，未切换明确中断；原版本重试与新发布分开 |
| 执行器暂停/异常 | 阻塞原因与下一步可见，编辑可继续，不把等待误报为正在构建 |
| 下线/归档/恢复 | 公共入口在成功下线后移除；归档受约束；恢复不自动上线 |
| 手机/平板/键盘 | 新建、上传、预览、发布可操作，无核心操作被遮挡或只能 hover 发现 |
| 权限与身份 | 服务器仍校验编辑/发布/配置/媒体权限，导航和本地副本不泄漏其他账号内容 |

### 真人独立试用

至少一位懂一点 Markdown、未参与开发的用户，在准备好的隔离环境中只收到任务目标：完成首次设置并发布含图片的文章；再次修改但先不发布并辨认网站仍显示旧内容；预览并发布更新；从一次可控失败提示找到下一步并完成恢复。

不提供点击步骤或口头指导，不预设完成时间；记录是否完成、误解、阻断、求助及采取的操作。若需要指导或出现阻断，记录卡点并修复后复验，不能由自动化测试替代该结果。环境准备不等于已验收真实部署。

### 工程检查与证据

按变更执行现有 Taskfile 入口；Admin 修改执行 task admin:lint、task admin:build；日期变更执行 task admin:date:check；后端变更执行 task backend:check 与受影响的双数据库合约；最终执行 task check。构建嵌入边界变更追加 task build:check。

浏览器复用本机 Playwright 1.63.0 / Chromium 153.0.8010.12，不通过 npx 下载新版本。故障验证使用隔离 runtime 与数据库，不对作者当前站点注入故障。证据记录实际环境、步骤、观察结果及未执行原因；运行数据留 .runtime/，不提交账号、草稿、密钥或真人个人信息。

实现前需核实当前 API/DTO 与页面 Patterns。浏览器存储选型、差异组件、必要查询/幂等接口属于实施选择，需证明上述行为，不能以技术选型替代验收。
