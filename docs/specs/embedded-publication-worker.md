## Problem Statement

作者通过 task dev 或 CMS 主程序编辑并发布文章时，需要额外启动 worker，否则任务一直等待，难以辨别缺少进程、构建环境或执行器故障。独立执行器的启动负担不符合当前单机博客使用方式。

## Solution

CMS 默认托管发布执行器，启动后自动处理持久化队列。后台提供状态、错误、暂停和恢复操作；发布不可用时仍能编辑。保留独立 worker 模式，公开站点服务保持独立。

## User Stories

1. 作为作者，我希望启动 CMS 即可发布，以减少进程管理。
2. 作为作者，我希望发布异步执行，以继续编辑文章。
3. 作为作者，我希望构建失败不终止 CMS，以保存工作稿。
4. 作为作者，我希望看到执行器状态和最近错误，以理解等待原因。
5. 作为作者，我希望缺少 Node 或 Astro 时得到明确提示，以修复环境。
6. 作为作者，我希望依赖修复后自动继续队列，以避免重启。
7. 作为作者，我希望单次失败不阻塞后续任务，以处理其他发布。
8. 作为作者，我希望中断任务明确要求重试，以避免意外再次发布。
9. 作为运维人员，我希望关闭内置执行器，以使用独立构建进程。
10. 作为运维人员，我希望两个执行器不能同时切换站点，以保护线上一致性。
11. 作为作者，我希望暂停后仍能编辑，以执行维护。
12. 作为作者，我希望暂停期间可以排队，以在恢复后发布。
13. 作为运维人员，我希望暂停等待当前任务结束后释放锁，以安全清理。
14. 作为运维人员，我希望恢复前重新核对指针，以防未知版本被覆盖。
15. 作为运维人员，我希望退出最多等待当前任务 30 秒，以控制重启时间。
16. 作为作者，我希望切换后的中断可以补齐记账，以保持真实发布状态。
17. 作为读者，我希望 CMS 停止时已发布站点仍可访问，以获得稳定访问。
18. 作为管理员，我希望暂停恢复受服务端权限保护，以避免未授权中断发布。
19. 作为作者，我希望临时基础设施故障自动退避恢复，以减少人工干预。
20. 作为运维人员，我希望维护工具默认只报告，以审查将删除的文件。

## Implementation Decisions

- Publishing 提供执行器生命周期管理，复用现有 Worker、BuildExecutor、持久化任务和站点锁；Builder 仍执行独立 Node 子进程，不在请求内构建。
- publication.worker_enabled 默认为 true；关闭时主程序显示 disabled，独立命令继续可用。状态接口描述当前 CMS 托管执行器，不猜测外部进程是否健康。
- 执行器状态包含 disabled、starting、running、pausing、paused、unavailable、lock_occupied、retrying、blocked、stopping、stopped；携带最近错误与当前任务 ID。
- 暂停是异步请求，立即停止领取新任务；当前任务结束并释放站点锁后才进入 paused。暂停允许入队。恢复重新检查构建环境、锁和持久化发布状态。
- authenticated GET /api/v1/publication-worker 读取状态；POST /api/v1/publication-worker/pause 与 /resume 控制内置执行器。读取复用内容编辑或发布权限；控制复用 content:publish。关闭内置模式时控制操作返回冲突。
- 缺少构建环境拒绝新增发布、下线、配置发布、Astro 预览和重试；幂等请求仍返回已存在任务。已有任务保留。定期检查环境修复；Markdown 编辑预览不受影响。
- 锁被占用时 CMS 继续编辑；内置执行器退避等待锁，独立 worker 获取失败退出。临时数据库故障退避并先恢复状态；未知指针等严重故障保持 blocked，修复后显式恢复。
- 退出停止领取，当前任务最多等待 30 秒，然后取消构建；数据库在执行器完成退出后关闭。未切换任务中断后手动重试；切换后的任务通过现有恢复机制补齐记账。
- 不增加数据库表；执行器生命周期状态属于进程状态，任务与部署恢复仍以数据库和发布指针为准。进程重启不保留维护暂停，维护必须在停止自动重启的前提下执行。
- task dev 去除额外 worker 进程，保持独立公开静态服务和 Astro 开发服务器。

## Testing Decisions

- 只验证可观察行为，复用认证 HTTP 集成入口、真实 SQLite/PostgreSQL、现有 BuildExecutor 和站点锁。
- 验证默认托管、权限、暂停期间排队、释放锁、恢复、锁争用、依赖缺失与恢复、普通失败继续、数据库故障恢复、指针阻塞和退出取消。
- 慢构建及故障使用现有 BuildExecutor 替身；真实 Astro 发布合约验证产物及恢复边界。
- 执行 task check、task build:check、双数据库集成；未执行的浏览器和跨平台检查明确记录，不以静态检查替代。

## Out of Scope

- 合并公开静态 HTTP 服务；下载 Node 或依赖；后台执行实际磁盘清理；分布式执行器；部分构建优化及全站重建新功能；源码推送和关闭远端 Issue。
