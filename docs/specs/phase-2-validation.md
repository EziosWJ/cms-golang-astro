## 可重复浏览器入口

先准备隔离的已迁移 API（启用发布执行器）和连接该 API 的 Admin。将 `CMS_WORKFLOW_URL` 指向这个 Admin，`CMS_PLAYWRIGHT_MODULE` 指向本机已安装 Playwright 的 package.json，`CMS_CHROMIUM_PATH` 指向已验证 Chromium 可执行文件，然后执行 `task admin:workflow:check`。可用 `CMS_WORKFLOW_USER` / `CMS_WORKFLOW_PASSWORD` 指定隔离测试账号，默认使用开发 seed 账号。入口校验工具版本，不下载或安装浏览器。
