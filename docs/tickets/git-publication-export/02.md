# [Ticket Git-02] 在后台连接 GitHub 并选择仓库与源码版本

GitHub：[#53](https://github.com/EziosWJ/cms-golang-astro/issues/53)

## Parent

https://github.com/EziosWJ/cms-golang-astro/issues/51

## What to build

作者在管理后台填写 GitHub fine-grained PAT，检测连接并选择现有公开输入仓库、目标分支和公开 CMS/Astro 源码分支或标签，无需服务器 Git 配置。

## Acceptance criteria

- [ ] 完成连接页面、后端接口及独立持久化模型；首版仅一条 GitHub 连接，不创建仓库，不导入远端文章。
- [ ] 检测 Token 与仓库读取、Contents 写权限；支持空仓库的目标分支配置；私有目标仓库明确拒绝。工作流由作者安装，不要求 Workflows 写权限。
- [ ] 源码默认使用公开 CMS 项目，可选择公开仓库的分支或标签；页面说明后续任务固定 SHA，未提交本地模板不进入 CI。
- [ ] 凭据以独立 AES-GCM 加密存储；首次生成运行目录主密钥，目录 0700、文件 0600；已有密文但密钥丢失时不覆盖密钥，要求重新连接。
- [ ] Token 只写不读，不进入浏览器持久存储、普通配置响应、日志、审计、URL 或构建输入；错误消息脱敏。
- [ ] 连接管理、推送和查看权限分别注册并默认赋予管理员，前后端均执行权限校验；SQLite 与 PostgreSQL 显式迁移兼容。
- [ ] API 驱动连接、检测与配置读写流程，仅模拟外部 GitHub；覆盖无权限、失效凭据、私有仓库、密钥丢失及秘密不泄漏，并用既有浏览器环境验证页面。
- [ ] 执行适用的 Taskfile 后端与管理后台检查，记录结果。

## Blocked by

None (can start immediately).
