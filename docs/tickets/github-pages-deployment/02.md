# [Ticket Pages-02] 可配置 base：仓库变量与缺省推导

## Parent

## What to build

让部署地址的 base 可配置：优先读取仓库变量 `CMS_BASE_PATH`，未设置时按仓库名推导 `/<repo>/`。构建与 Pages artifact 使用同一个值，站点构建通过既有 `CMS_BASE_PATH`（Astro `base`）消费它，使以后切换自定义域名只改变量。

## Acceptance criteria

- [ ] 模板从仓库变量读取 base，缺省值为按仓库名推导的 `/<repo>/`；两种取值都产生正确的 Astro `base`。
- [ ] 构建与 Pages artifact 使用同一 base；切换自定义域名只改仓库变量，不改工作流与站点代码。
- [ ] 文档说明变量名、缺省值、设置与清除方法，以及切换域名时需要同时更新站点 `publicUrl`。
- [ ] 验证缺省推导与显式覆盖各一次，记录取值、部署地址与验收后的恢复动作。
- [ ] 不把仓库名或域名硬编码进站点代码；base 逻辑只存在于工作流与构建环境变量。
- [ ] 执行适用 Taskfile 检查，记录未执行项及原因。
