# [Ticket Pages-04] 远端 Pages 验收与记录

## Parent

https://github.com/EziosWJ/cms-golang-astro/issues/58

## What to build

用一次真实 push 触发的运行验收 Pages 部署，并按部署地址完成页面、媒体与边界检查，然后回写记录。本地检查与手动触发不作为远端部署成功。

## Acceptance criteria

- [ ] 记录一次真实 push 触发的运行：输入提交、固定源码 SHA、运行链接、部署地址与 deploy 作业结果。
- [ ] 按部署地址校验首页、文章页（中文 Slug 按解码后路径比较）、归档、分类、标签、404 与媒体；媒体 MIME 与字节哈希与输入校验和一致。
- [ ] 边界扫描实际发布的文件：不含 `export.json`、`manifest.json`、`.release.json`、日志、`master.key`、`.env`。
- [ ] 验证 base 生效：部署地址下 CSS 与媒体可加载，不因缺少 base 前缀而 404。
- [ ] 记录未执行项（如故障注入、自定义域名）与原因，不把本地检查当作远端部署成功。
- [ ] 回写规格/工单记录与对应 PR；执行适用 Taskfile 检查并记录结果。
