## Acceptance criteria

- [ ] **端到端闭环**：从 CMS 后台手动发起一次远端交付，走完构建 → 预部署 → 真实 HTTP 冒烟 → 生产提交 → 记录登记，全部阶段在界面上可见且与实际一致。
- [ ] **独立站点配置生效**：修改远端站点的站点名/主题/公开地址后再次交付，远端实际呈现随之改变，**而 local 站点与 local 产物完全不变**。
- [ ] **重复交付幂等**：内容与配置均未变化时再次交付，不重传内容未变的文件，且结果可核实。
- [ ] **上限前置检查**：构造超限输入（单文件超限 / 文件数超限），在**构建前**明确失败，不产生半成品上传。
- [ ] **私有预览不外发**：断言 `previews/` 与 `releases/` 均未被上传；通过远端实际枚举一次交付的文件集合核对。
- [ ] **失败语义实测**：至少实测「部分成功」与「待核实」各一次，确认线上保持在上一版、原因与下一步在界面上可见、且**不阻塞 local 发布**。
- [ ] **远端不可用不阻塞本地**：断开远端可达性后，本地编辑与本地发布仍可用，远端交付明确失败并保留记录。
- [ ] 执行适用 Taskfile 检查（`task check`、SQLite 与 PostgreSQL 集成验证），记录未执行项及原因。
- [ ] **文档收尾**：
  - [ ] `docs/adr/0003-self-hosted-static-publication.md` 标注「暂不接入远端部署平台」已被 ADR-0009 修订。
  - [ ] `docs/specs/phase-1-operations.md` 等出现「单站点指针」措辞处，标注其适用范围（仍指发布域，见 ADR-0009 决策二）。
  - [ ] `CONTEXT.md` 的站点与交付术语与最终实现一致。
  - [ ] 运维说明记录：数据库备份含远端凭据；远端交付不依赖 Git。
- [ ] **登记后续 ticket（不在本阶段实施）**：`deployment.Switch` 缺审计事件、publishing 缺 Prometheus 指标。
