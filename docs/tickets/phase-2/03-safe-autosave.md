## What to build

作者从首次输入开始获得可核实的保存反馈，网络或会话异常后可恢复未确认内容。

实现包括必要的界面、API、权限与错误恢复，不把任务限定为样式改动。沿用既有领域不变量，实际检查当前接口后选择最小实现。

## Acceptance criteria

- [ ] 有效标题/正文稳定约 2 秒后创建，空白不创建；组合输入不抢先保存。
- [ ] 每篇保存串行，旧响应不覆盖后续输入；首次创建响应丢失可恢复且不重复文章。
- [ ] 临时身份迁移至正式文章身份，副本按站点/账号/文章隔离，恢复与清除可操作。
- [ ] 副本存储受限时明确降级；不保存凭据/二进制/blob URL，不把本地缓存称为服务器已保存。
- [ ] 断网/刷新/同账号重新登录可提示恢复，其他账号不能在界面读取副本；未经确认不自动覆盖服务器。
- [ ] 冲突暂停自动保存，比较完整本地/服务器内容，明确采用服务器或经确认保存本地；再次变化仍冲突。
- [ ] 离开提醒、认证失败和手动留版并发不丢输入；自动保存不逐次产生修订。
