## What to build

作者在写作中完成分类标签选择，并在第一次发布前明确完成站点设置。

实现包括必要的界面、API、权限与错误恢复，不把任务限定为样式改动。沿用既有领域不变量，实际检查当前接口后选择最小实现。

## Acceptance criteria

- [ ] 按权限搜索多选/清空/快捷创建分类标签，直接选中新项，失败与取消保留文章输入。
- [ ] 冻结名称/URL 与引用保护沿用既有约束，不能借快捷创建绕过。
- [ ] 轻量设置清单不阻断写作；发布前校验完整必填配置，配置先发布成功再返回文章确认发布。
- [ ] 设置页区分当前输入、已保存配置与线上配置，展示差异和发布确认摘要。
- [ ] 配置保存不应用网站，独立发布结果与查看网站入口明确；失败可重试固定配置。
- [ ] 首次配置失败不提交文章发布、不丢原输入；未发布其他文章不混入配置发布。
