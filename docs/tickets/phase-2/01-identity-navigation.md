## What to build

作者登录后直接发现文章与写作入口，系统能力有明确次级入口。

实现包括必要的界面、API、权限与错误恢复，不把任务限定为样式改动。沿用既有领域不变量，实际检查当前接口后选择最小实现。

## Acceptance criteria

- [ ] 后台与登录页统一名称并显示站点名称；默认进入文章列表，保留安全登录返回路径。
- [ ] 文章支持全部未归档、草稿、已发布、有未发布修改与归档视图；筛选语义与线上事实一致。
- [ ] 标题可进入编辑，列表优先标题/状态/分类/编辑时间；保留搜索与返回位置。
- [ ] 权限点不作为业务导航入口；系统模块收纳不改变权限或语义。
- [ ] 加载、空态、失败、无权限可辨认；核实 API 是否支持筛选，必要查询在本任务实现。

## Blocked by

## Validation

Spec §1；浏览器验证筛选重叠、归档、返回位置和不同授权账号；task admin:lint、task admin:build，后端查询变更补双数据库合约。

执行前阅读项目 ADR、CONTEXT、Admin 规范和适用 Patterns；浏览器使用本机 Playwright 1.63.0 / Chromium 153.0.8010.12。检查未执行需说明原因。实际证据写入接续实施记录；不因编码完成勾选未经验证的条目。
