## What to build

作者能找到资源、看见上传结果，在光标位置插入图片或附件并安全管理引用。

实现包括必要的界面、API、权限与错误恢复，不把任务限定为样式改动。沿用既有领域不变量，实际检查当前接口后选择最小实现。

## Acceptance criteria

- [ ] 统一上传和单一资源集合/分页，支持文件名搜索、认证缩略图、附件信息。
- [ ] 单/批量上传显示真实进度或阶段；逐项失败可重试，响应丢失不造成无提示重复资源。
- [ ] 编辑内选择和截图粘贴按选区插入稳定路径，失败不写虚假路径；成功资源可重新选择。
- [ ] 封面/头像可见缩略图；详情含大小、图片尺寸、引用来源。
- [ ] 删除前说明影响，全部类型引用与底层删除入口保护仍生效；无权限正确反馈。
- [ ] 手机可上传选择，私有文件保持认证访问，浏览器 Object URL 正确释放。
