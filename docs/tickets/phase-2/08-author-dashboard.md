## What to build

作者可以从概览找回编辑与发布上下文，日常页面的术语和反馈一致。

实现包括必要的界面、API、权限与错误恢复，不把任务限定为样式改动。沿用既有领域不变量，实际检查当前接口后选择最小实现。

## Acceptance criteria

- [ ] 展示授权范围内真实最近编辑、未发布修改、最近发布结果和写作/查看网站入口。
- [ ] 没有内容或尚无网站时显示指向下一步的空态，无假数值、内部路由和权限点卡片。
- [ ] 保存/发布/重试术语与文章、设置、发布记录一致，链接能返回相关业务上下文。
- [ ] 加载、失败、无权限与执行器异常有可操作反馈；最小查询 API 在需要时补充，不前端只取第一页伪装完整统计。
