## What to build

作者能看到自动保存状态，查看手动保存历史并恢复旧修订继续编辑。自动保存和恢复都不改变线上内容；在发布能力接入前验证工作稿与不可变修订边界。

## Acceptance criteria

- [ ] 防抖自动保存按文章串行请求，更新工作稿及版本号，不逐次追加历史修订。
- [ ] 后台清楚显示保存中、已保存、失败、冲突；失败保留编辑内容，冲突不自行覆盖服务器版本。
- [ ] 通过修订列表/详情和恢复操作选取旧完整快照；恢复使用 expectedVersion，仅写工作稿，历史修订不变。
- [ ] 手动保存与自动保存并发时不丢失内容；之后接入发布时可等待在途保存完成并固定正确版本。
- [ ] 修订永久保留，不提供删除或版本差异比较；线上版本由发布流程选择，恢复操作没有发布副作用。
- [ ] 通过浏览器多标签页与认证 HTTP+双数据库契约验证自动/手动保存和恢复，执行适用 Taskfile 检查。
