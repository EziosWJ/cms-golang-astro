## What to build

站点已经有文章后，作者可明确发布站点/作者配置及头像；此操作只更新配置，文章维持线上版本。保存配置或发布文章都不会把未发布配置顺带上线。

## Acceptance criteria

- [ ] 工作配置保存、所选配置修订、线上配置独立；发布配置固定版本并持久化幂等任务，不读取后续编辑。
- [ ] 有 A/B 工作稿修改时发布配置，A/B 仍为线上版本；配置修改尚未发布时发布文章，线上配置保持旧值。
- [ ] 新的名称、简介、公开地址、语言、时区、作者信息及头像在成功切换后的实际页面生效。
- [ ] 任务失败保持原配置与文章站点；配置冲突/权限/无效头像在后台及服务端明确反馈。
- [ ] 配置与文章操作共用最新 release 基线和串行队列，先后操作不相互撤回；引用保护包含旧配置快照与保留产物。
- [ ] 通过后台操作、认证 API、真实静态站点与双数据库合约验证隔离，执行适用检查。
