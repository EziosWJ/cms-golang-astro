## What to build

作者能明确下线文章，站点成功更新后再归档；读者的详情、列表与分类标签入口同步移除该文章。归档保留正文、修订和 Slug，恢复后可继续编辑但不会自动上线。

## Acceptance criteria

- [ ] 下线使用幂等发布任务，以当前线上基线移除目标文章，其他文章和配置保持；成功前原站点与状态继续有效。
- [ ] 详情、列表和所有分类标签入口随同一次成功切换移除；失败保持原站点和可见记录，错误可查询。
- [ ] 只有未上线或成功下线、且无相关排队/执行发布操作时才能归档；并发发布/下线/归档在服务端一致校验。
- [ ] 归档退出默认列表、停止保存/恢复工作稿等编辑；归档列表允许查看并恢复生命周期。
- [ ] 恢复归档变为可编辑，不自动发布；原 Slug 继续占用且若曾上线则冻结；正文、不可变修订和媒体引用不丢失。
- [ ] 不提供永久删除，不承诺撤回已下载的媒体或历史缓存；当前产物不继续导出目标文章独占资源。
- [ ] HTTP 并发合约、后台完整下线/归档/恢复路径、静态入口及双数据库测试通过，执行适用检查。
