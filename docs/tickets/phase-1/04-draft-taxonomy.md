## What to build

作者能分别管理分类和标签，在文章编辑器中多选或清空，并在手动修订中保留当时的名称快照。本票完成后台组织内容路径；实际站点聚合与首次发布锁定由后续发布分类票据接入。

## Acceptance criteria

- [ ] 分类和标签有独立稳定身份、名称和 URL，平面结构，无父子层级；一篇文章可多选且可为空。
- [ ] 分类/标签管理、文章表单、保存 API、工作稿及修订快照使用真实持久化数据。
- [ ] 尚未对外发布的项可改名，历史修订不会被回写；被工作稿或修订引用的项不可删除，服务端直接请求同样受保护。
- [ ] 预留真实首次发布锁定语义，不能以保存草稿或生成修订冒充对外发布。
- [ ] 名称与路由兼容旧博客，多分类不会被强行转换为单分类。
- [ ] 权限、冲突错误和引用保护在后台有可理解反馈；以 HTTP/管理操作和双数据库契约验证，执行适用检查。
