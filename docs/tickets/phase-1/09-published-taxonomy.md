## What to build

作者能发布含多个分类/标签的文章，读者能浏览分类标签聚合页；首次成功上线冻结组织身份，草稿修改和旧修订不会悄悄改动已公开名称或地址。

## Acceptance criteria

- [ ] 发布快照纳入所选修订的分类/标签，保留其他文章线上组织关系，不读当前其他工作稿。
- [ ] 生成分类/标签列表与各项文章聚合入口，URL 保留旧名称编码规则，无单分类强制转换。
- [ ] 成功切换才冻结名称和 URL；排队/执行保护身份，失败不冒充首次公开；未发布项可按规则改名。
- [ ] 所有编辑/删除入口阻止已冻结改名和引用项删除；恢复历史名称与已锁定身份冲突时报告并要求重新选择。
- [ ] 再次发布改变分类归属时更新全部聚合入口；不存在将其他草稿分类顺带上线或历史快照被回写。
- [ ] 通过后台选分类→发布→读取页面→尝试改名/恢复的完整路径及双数据库约束验证，执行适用检查。
