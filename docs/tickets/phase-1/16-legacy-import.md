## What to build

作者能通过受控导入入口盘点并导入旧 Markdown 内容，获得冲突/兼容报告；导入后可在后台编辑并通过既有发布流程上线，旧文章、媒体、多分类和日期保持。导入不成为持续 Markdown 双主数据同步。

## Acceptance criteria

- [ ] 导入前核实实际旧源码/内容版本，支持预检盘点；本地已调查的 95 篇只作为基线，不假设等于线上最新。
- [ ] 受控入口提供可审阅导入结果并能从后台查看导入文章；报告标题、正文、日期、Slug、多分类、标签、封面与媒体映射的完整性。
- [ ] 保留中文/数字 Slug 和旧文章 archives/尾斜线路由，以及既有图片/附件地址映射；冲突报告且不静默覆盖。
- [ ] AST 处理正文链接与媒体，修正可解析的相对文章链接；无法解析、不兼容内容与重复路径明确报告。
- [ ] 迁移原展示日期和已有更新时间，不使用导入时间替代；导入为 CMS 管理的工作稿/修订，明确发布才上线。
- [ ] 按稳定来源身份/指纹重跑无重复文章或媒体；部分失败可追溯并可安全再次导入，不能读生成文件反写内容。
- [ ] 真实旧内容或可取得的同源夹具通过数量/关系校验、GFM 表格、代码高亮/语言标签、标题锚点与媒体下载验证。
- [ ] 上线验收核实旧 URL 实际编码和渲染；未提供线上访问条件则明确保留待验收项，旧主题与页面布局不纳入本票。
- [ ] 导入权限与审计、后台继续编辑→发布路径、双数据库兼容和适用检查通过。
