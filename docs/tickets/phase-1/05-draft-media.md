## What to build

作者能复用现有上传能力上传图片/附件、选择已有资源、插入正文和设置可选封面；后台即时预览能认证读取文件，同时持久化稳定引用并保护历史。本票不把上传资源自动公开。

## Acceptance criteria

- [ ] 复用 filemgmt 存储及单/批量上传，完成媒体身份、选择入口和封面绑定，不另建上传服务或公开源目录。
- [ ] 上传成功才插入正文；失败显示错误且不留下假引用。持久化稳定媒体路径，不保存 blob URL 或带认证的文件访问 URL。
- [ ] 即时预览使用认证 fetch/Object URL 或等效受控加载；匿名不能读取上传源文件。
- [ ] AST 提取正文图片/附件与封面引用，忽略代码中的示例地址；外部 HTTP(S) 链接保留，不自动抓取或代理。
- [ ] 更新工作稿、追加修订、恢复引用的操作保持事务一致；旧修订引用继续保护资源。
- [ ] 所有系统文件单删、批删及媒体删除入口执行内容引用保护；保留原软删除/停用语义，停用不冒充下线。
- [ ] 验证实际媒体类型和稳定身份；替换文件内容上传新资源；API 服务端权限与引用错误不能仅依赖按钮显隐。
- [ ] 通过后台上传/插入/预览/删除与 HTTP 双数据库集成证明行为，执行适用检查。
