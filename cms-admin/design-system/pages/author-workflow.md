# 作者工作流页面覆盖

文章列表沿用 Standard List：PageHeader、SearchFilterBar、DataTableCard、Pagination。标题直接进入编辑，默认未归档；已发布与未发布修改的筛选可重叠。

写作页是 Standard Form 的业务变体：标题与 Markdown 正文先出现；源码 / 正文预览 / 分屏切换，宽屏元信息、分类与媒体收入可折叠侧面板；平板堆叠，手机使用设置弹层。固定底部操作区参与文档布局、允许换行，避免覆盖正文末尾。桌面分屏，窄屏上下排列。冲突及历史比较复用字段对照，文本通过 React 转义显示。

媒体库采用 Standard List + Upload Section，只有一个主集合与分页。上传按文件显示等待、上传中、成功或失败，不提供虚构百分比；逐项重试沿用请求身份。编辑内媒体选择复用同一上传区块及认证缩略图。

工作台使用真实 API 数据、权限控制和空态。发布结果优先状态与下一步，执行器控制与尝试标识收在诊断 / 维护展开区。
